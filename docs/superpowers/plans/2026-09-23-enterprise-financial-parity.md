# 企业预警通六栏目界面对齐增量计划

Goal: 六栏目及全部下级的数据、布局与真实交互逐项对齐；不是仅复制工具栏外观。

Architecture: 保留现有三实体、四接口、Task/worker；模块原始 JSON 存储，读取时形成视图。企业预警通与 PDF 来源隔离，公式仅 warning。

Tech stack: Python/FastAPI/SQLAlchemy、独立 Playwright、React/TypeScript、现有财务 CSS。

Spec: 用户已确认的最小接入设计及 2026-09-23 六栏目完整复制要求；原站实页是交互和展示依据。

Global constraints: 在 main 增量修改；不调用 Agnes、不迁移铭普光磁、不新增实体或接口、不输出凭据、不复制浏览器配置；保护无关 M2 修改。仅关闭精确确认并获授权的专用浏览器进程。

Review focus: 假控件、期间与值错位、元/万元/每股混淆、空值变零、汇率猜算、部分批次覆盖完整批次、分析与附注层级丢失。

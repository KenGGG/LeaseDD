# Agnes 主导的通用财务语义识别

用户提供的架构要求为本次实施依据：结构发现不依赖公司或财务标题，Agnes 负责文档分类、报表元数据和逐行科目映射；本地负责来源、数字、单位、期间、勾稽和冲突核验。暂不增加指标或附注分类。

## 边界与职责

- 保留 MinerU / MarkItDown 转换和材料外发授权。未授权材料只做本地处理，不能静默发送模型。
- 已授权的新识别任务必须进入 Agnes 流程，不能因本地发现部分表格提前成功。本地旧解析作为第二意见。
- 文档地图包含标题层级、物理表格、原文前后文、单元格坐标。Agnes 可把多个物理块归为一张逻辑表；合并/母公司混排由列元数据表达。
- 分为 map、interpret、extract 三类模型请求。先确定表格语义、列期间/范围/单位，再映射整表所有行。未知科目保留为 unmapped；标准科目不是提取白名单。
- 金额必须指向具体原文单元格，不能仅检查同一段是否出现相同数字。原始值永远从源单元格读取；模型返回的抄录值用作交叉核验，不能覆盖原值。
- 货币资金与现金及现金等价物保持独立概念；不因文字相似强行归一。VERIFIED 表示程序核验，不代表独立人工审核。
- 元数据无证据、歧义、模型/本地第二意见冲突均留为待核对。缺项不补零，错误数不进入可计算 VERIFIED 集合。
- 512K 上下文、65K 输出按用户提供限制配置；使用保守 UTF-8 字节预算防超上下文，不冒充精确 tokenizer。优先保留完整逻辑表；超过预算时按行拆分且保留表头、列元数据和原坐标。
- 全局凭据级滚动 60 秒限流默认18次、上限20次；每次重试也占额。429遵守Retry-After并共享冷却。单块总尝试不超过3次，成功块可复用。
- 任务续租，恢复时按输入/模型/版本/请求摘要匹配检查点；失去租约不能提交结果。重识别保留历史批次和来源，不能删除人工确认或静默混合批次。
- 检查三表发现情况、核心科目、资产=负债+权益等已具备输入的勾稽。针对缺失行/核心项，只对相关表发补查，不重跑整份文件。

## 验收

通用合成样例覆盖标题变化、跨页、多级表头、混排、未知科目、单位/期间歧义、数值相同但坐标错误、伪造值、部分遗漏、断点、限流、无外发授权。基准框架强制按企业隔离开发/holdout，明确分子分母和误验率；现有四份同企业文件不构成跨公司验收。真实10企业20–30文件及独立标注尚未提供，必须明确留作未通过项。

# Agnes 主导识别升级验收（2026-09-20）

## 本次实现

授权的新识别任务采用：转换 Markdown → 发现物理表格与单元格 → Agnes 分类文档 → Agnes 解释主体、口径、单位和期间 → Agnes 逐行提取 → 本地核验及定向补查。

结构发现不判断财务语义，不按公司名匹配。原本的财务解析器保留为第二意见；它找到部分表格时也不能跳过 Agnes。未授权材料使用明确标识的本地模式，不发送模型。此次部署不自动重识别历史材料。

每个数值绑定原表、行、列及 Markdown 行号。原始值从源单元格读取，模型不能覆盖。支持同一逻辑表跨物理块合并；主体、范围、币种、期间或单位不同不能合并。年初余额可对应上一年年末，保留原期间证据。货币资金和现金及现金等价物使用不同概念。

逐行提取不限于已有标准科目：未知科目保留原名和原值，标记未匹配。缺项、错误单位、错列、来源冲突及三表勾稽问题不能进入自动计算。程序核验状态不代替人工审核。

三表检查包括资产与负债权益平衡、利润总额减税等于净利润、三类现金流加汇率影响等于净增加额、期初现金加净增加额等于期末现金。缺少输入时显示缺口，不补零。

共享限流按凭据跨任务执行，默认每分钟18次，最多20次；429冷却共享，重试同样占额度。上下文及输出使用保守预算，不声称精确分词。成功阶段保存完整性摘要；同一任务重启可复用，每阶段总发送最多3次。主动重识别创建新任务和新批次，不承诺复用上一个任务的阶段。失去或过期的租约不能续租、保存或发布新结果。

## 使用与历史

在“资料与证据”页上传所有材料后，勾选文件及“使用 Agnes 识别财务语义”，点击“批量识别”。旧文件需先勾选“重新识别已完成资料”。默认显示简短中文结果与数量。保留原件和旧识别批次；默认财务表选择各文件最新完成且有候选数据的批次，失败空批次不会覆盖先前可用数据。

批次清单通过项目鉴权接口 `/api/projects/{pid}/financial-extractions` 查询；指定批次用 `/financial-statements?run_id=...`。网页尚未提供历史批次切换器。

# 财务报表展示改造验收

日期：2026-09-20。

## 参考与目标

通过 Quantradar 的独立 Chrome 配置和浏览器保存的登录状态，查看企业预警通「东莞铭普光磁股份有限公司 → 财务数据 → 资产负债表」。未关闭或重启用户桌面 Chrome、远程桌面；未读取或输出保存密码。参考页面为 https://www.qyyjt.cn/detail/enterprise/financialStatements?code=5C36774FC05682B8AD4996EA6B0325CB&type=company 。

观察到左侧栏目导航、上方报告期／年度／口径／单位筛选、报告期倒序、隐藏空行、导出，以及按科目分组、多报告期横向并排的金额表格。参考截图保存在 `runtime/reference/qyj-home.png`。参考公司的财务数据未写入 LeaseDD 的项目数据。

## 已交付

- 将原来的逐张候选列表改为三张财务报表矩阵，默认显示资产负债表；固定科目列与表头，分组、交替底色、合计加粗、金额右对齐。
- 主体／口径／币种严格分组；未知口径额外按原件隔离。期间键包含完整期间及类型，半年累计与单季度不合并。
- 全部／年报／中报／季度、起止年度、近 3／5／10 年、倒序、隐藏空行、科目搜索。
- 元、千元、万元、百万元、亿元和 0／2／4 位小数。显示换算用 BigInt 十进制整数运算，不经二进制浮点；保留原数据，未进行币种兑换。
- 零与缺失分别展示；未能验证来源的值不作为普通金额展示；不同精确值保留冲突，不因显示舍入相同而消失。拒绝候选保留在来源列表中。
- 点击金额查看所有候选、原件名称、原始数值、币种、期间、Markdown 行号、口径问题和核对意见；通过现有鉴权接口读取原文、下载原件和确认／拒绝。
- 当前视图 CSV 导出附来源对照、候选 ID、核对状态；防止文本被表格软件当作公式执行。导出是待核对表，不是正式报告。
- 原来的三个指标及人工事实导入移至「主要财务指标」，沿用既有计算、权限和审核边界。

## 边界

本次是展示层改造，无数据库迁移或新增生产财务公式。当前提取契约支持 52 个标准科目；页面不编造未提取的数据，上传报告缺期、提取遗漏或口径不清仍需核对。主要财务指标仍来自人工事实通道，自动三表到指标的映射和公式验收未完成。未实现参考网站的全套财务分析、单季拆分、同业比较、财务附注、行情和汇率服务；导出为 CSV，不是原生 XLSX。合成验收不能替代真实报告的财务准确性验收。

后续半年报修复已新增源表单元格读取，52 个标准科目之外的披露行也会保留，见 [半年报专项验收](half-year-extraction.md)。

## 原表排列与核对体验优化（2026-09-20）

- 默认按最新报告的原表顺序和分组展示，其他期间独有科目追加展示；可切换标准科目顺序。新增披露科目能够跟随原表位置，不再统一落在表格末尾。
- 来源弹窗显示原表列头和该行单元格，并突出当前原值；原始 HTML 以折叠文本保留，页面不执行原文标记。
- 增加全部数值、待人工核对、存在冲突、已确认筛选及数值计数。筛选保留匹配科目的所有期间用于对照。来源已通过程序校验但未经人工确认的数值仍计入待核对；有口径问题的已确认候选也不会被列为有效已确认值。
- 展示信息只从摘要核验通过的 Markdown 读取，不迁移数据库、不重跑提取、不改金额或人审记录。缺失提示改为“原文空白或未提取”，不把原表空白误说成识别遗漏。
- 后端 86 passed、2 skipped；前端 11 项测试通过；TypeScript／Vite 构建通过。专项浏览器验收通过排列切换、冲突筛选、确认后筛选、可读来源、导出及移动端检查，无页面脚本错误。
- 已部署 API 与 Web，保持局域网 5173 端口，worker 和数据库未重启。部署后只读检查现有半年报：12 组、422 个数值全部能定位到唯一源行，源文件摘要有效，写入次数为 0。
- 最新截图与浏览器结果保存在 `runtime/acceptance/financial-workspace/`。截图使用合成验收数据，服务器上的真实半年报另经只读核验。

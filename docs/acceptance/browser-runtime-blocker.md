## 修正：插件不是应用采集器的前置依赖

已读取 Quantradar 的 `backend/quantradar/research/collector/qyj.py`：应用直接使用 Python Playwright 启动 Chrome 持久化上下文，不依赖客户端 Browser/Chrome 插件。先前将插件故障视为整个采集链路无法运行的结论过宽。

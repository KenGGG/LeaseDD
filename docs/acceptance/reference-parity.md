日期：2026-09-20。此记录替代旧验收文档中“自动报表尚未接入指标”“未实现财务附注”的现状描述，保留其历史测试结果。

## 本次交付

- 财务页隐藏流程条、测试徽标、逐格待核对文字及大段说明；指标和附注默认显示筛选与对比表。计算依据、来源、异常原因只在点击后展开，人工事实导入位于“更多操作”。
- 主指标按参考平台的 48 个数据行排序；分析栏目按实际页面的每股、盈利、偿债、营运、成长、现金流、杜邦行名展示。参考站的历史列不会伪装成已上传资料。
- 摘要补充扣非归母利润、披露的加权 ROE；股本变动表读取明确的股份数量；现金流补充资料读取折旧与摊销；补充资料读取扣非 EPS 与扣非加权 ROE。均保存稳定来源标识和原文定位，通过原 Markdown 摘要校验后读取，不覆盖已有事实，不伪造人工确认。
- 使用原币 Decimal 计算。比率按参考显示为百分数；每股值四位小数；损失在主要指标中按损失为正的口径显示，原始利润表数值保留；负基期增长采用 `(本期−同期)/|同期|`；周转天数采用明确的 30/360 口径。
- ROE 直接使用披露的加权值，平均和摊薄 ROE 分别使用归母净利润及相应归母净资产。半年累计和单季度分离；同比、环比、年初增减分别使用明确基期。
- 债务和 EBITDA 使用本版列明的融资余额及折旧摊销公式，公式可点击查看。这是针对已提供报告核对过的定义，不能当作已确认的全行业生产公式；应付债券、应付票据等项目的处理仍需完整口径验收。
- 附注支持审计信息、主营构成和有明确期间列的明细矩阵；存货将“在产品”和“半成品”归入“在产品及半成品”。保留账面价值、期末余额、跌价准备以及每个来源。不同项目鉴权，不同主体、合并/母公司分开；冲突值不静默覆盖。
- 未形成结构化矩阵的附注仍可通过“查看原文”阅读。现阶段并非所有附注都已完全结构化，也非参考平台的全量复制。

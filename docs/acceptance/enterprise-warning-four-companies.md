# 企业预警通四家公司验收

## 结论

2026-09-22 至 2026-09-23 使用当前已登录的 Quantradar 浏览器配置，对金银河、德方纳米、气派科技、昊志机电执行了真实结构化财务导入。四家公司均明确匹配到上市主体，未迁移或修改铭普光磁项目，企业导入路径的 Agnes 调用均为 0。

逐项点击并核对真实页面后，财务附注从 6 项补全为 10 项，新增受限资产、财务费用、非经常性损益和长期应收款。同时修复虚拟列表中间项定位、财务分析期间字段变更及旧版矩阵接口。四家公司均完成 21 个模块导入：

## 已证明与未证明

- 已证明：真实搜索可保留全部候选并明确选择上市主体；21 个模块的原始 JSON、请求口径、响应摘要和空值可以按模块保存；三张表可进入现有视图和七条公式；公式异常只报警；企业导入不调用 Agnes。
- 最终数据库只读核验显示：四家公司最新批次均为 `completed`，每批 21 条模块数据，失败模块为 0。
- 补齐“非流动资产合计”、“非流动负债合计”及带“加/减”前缀的公式科目映射；现金流量表同名补充行保留原值，但不作为重复公式输入。
- 部署后按真实数据库逐期运行七条公式：德方纳米、气派科技、昊志机电各 49/49 条通过；金银河 48/49 条通过，唯一未检查项是 2023 年三季报“汇率变动对现金及现金等价物的影响”来源值为空，未补零。
- 本结果只代表这四家公司和当前企业预警通页面版本，不代表任意公司或未来页面版本。

详细去敏数据见 `enterprise-warning-four-companies.json`；文件不包含认证信息、请求头、登录信息或授权数据原值。

## 2026-09-24：40 项目录的生产再验收

只读重跑验收脚本的当前结果见 [`enterprise-warning-four-companies-current.json`](enterprise-warning-four-companies-current.json)。旧版脚本曾以 21 项为满额，且发现 40 项批次时会误触发重新导入；现脚本仅读取当前批次，已移除刷新/采集选项，不访问采集器、不创建任务。结果将有数据项与原站禁用项分开计数，并按 Task 的不可变企业代码核对项目绑定。四家分别为 30+10、31+9、29+11、32+8，均无失败或缺失目录项。主表的 `period_counts` 计来源列（包含同一期间的不同口径/数据类型），附注的 `record_group_counts` 计来源记录组或日期键记录行，二者都不等于人工核对的不同报告期数。该报告是数据库只读核对；未再次人工点击原站全部子栏，也不能证明所有界面已完全一致。

上文 21 项是历史批次，本节记录新版目录的实际生产导入。四家公司仍为原项目，没有创建假文档，也没有迁移铭普光磁。为执行管理员手动导入，曾对这四个项目临时增加 `admin` 编制成员；所有任务完成并验证后，四条权限均已撤销，原编制/复核成员不变，撤销亦有审计记录。

每家公司数据库均有 40 条模块记录，分类固定为指标 1、三表 3、财务分析 7、财务附注 29；禁用项标为 `unavailable`，不是财务空值或采集成功的数值项。四批原始模块哈希全部可从保存的原始响应复算，主要指标与三表每家公司 72 个原始币种/汇率响应重新解析后与保存的解析层一致。逐单元格核对三表读时投影与保存的原始科目、原值、行号、期间列号及响应摘要：金银河 40,897、德方纳米 33,732、气派科技 27,720、昊志机电 41,072 格，合计 143,421 格，错位 0。这是**数据库内来源一致性**，不是人工逐格复核企业预警通网页。

生产 API 对四家公司分别返回当前完成批次及 40 项目录，批次 ID 一致。德方纳米生产网页实际点击主要财务指标、资产负债表、利润表、现金流量表、盈利能力、审计报告，分别显示 67、76、44、71、32、7 行，页面异常与可见报错均为 0；主要指标切换美元/最新汇率后表格内容改变，再切亿元并下载 Excel。Excel 首期「营业总收入」为 `15.416481963996508` 亿元，与保存的美元/最新汇率原值 `154164.81963996508` 万元精确换算一致；审计报告 Excel 也完成真实下载。其余工具栏组合和全部附注布局尚未逐项人工对照。

德方纳米 2013、2014、2015 年母公司早期资产负债表有 3 条 `资产=负债+权益` 冲突，原站同列原值也不满足公式；保留报警和原值，不改数。其余 `未检查` 主要对应未披露或空白输入，未补零。生产还发现原站利润表存在 `8.0E-6` 这类科学计数法；解析修复后保留原文、按 Decimal 换算，来源状态改为已核实，德方纳米公式通过数由 267 增至 271。异常指数长度设有上限以防不合理格式化。

首次采集金银河的欧元/最新汇率资产负债表响应曾返回 `returncode=104`，单模块重试后成功；气派科技首次遇到 `browser_unavailable`，重试后成功。当前没有同四家公司、同披露范围的 PDF + Agnes 耗时基线，也没有全部源站界面/导出逐项对照，因此**不能宣称六栏目已完全复制或量化加速**。原站本次禁用项是否会在其他日期开放亦需后续刷新验证。

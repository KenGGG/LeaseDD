## 已验证的原站筛选契约

主要指标请求仍使用 `report/getMainIndicators`，三表使用 `report/getThreeReports`。真实点击验证了：

- 报告期多选：最新、年报、三季报、中报、一季报；`reportDate` 是具体日期数组，`reportDateType` 是最新具体日期加报告类型后缀。
- 报表类型多选：`mergeRange=1` 合并、`1,2` 合并与母公司。同一期间可以返回两列，必须按每列 `dataType` 区分。
- 单位：万元 `unitCode=4`，亿元 `unitCode=8`。`headExport` 中的显示单位比数据库字段单位直接。
- 币种：披露币种 `displayCurrency=O`，美元 `USD`；菜单另有人民币、日元、港元、英镑、欧元、加拿大元、澳大利亚元。
- 汇率：期末 `rateType=1`，最新 `2`。金额由原站按该选择返回，不可猜算汇率。
- 初始默认窗口只有近年选定期间，不是全部历史。年度范围与完整可选历史机制尚未完成接入。
- 原站保留部分上次筛选偏好，采集不能依赖浏览器当前默认单位和口径。

认证可靠性实测：不带原站认证头的普通浏览器 `fetch` 曾返回 `returncode=200, info=暂无相关数据`，但同页点击确实有数据。复用 Quantradar 的短期请求头白名单后，直接请求恢复；头只留在会话内存，关闭清除，不进入模块 JSON/参数/hash。

「财务费用」默认源文件与当前生产导出均为 `11×13`，但 73 个金额格在源文件为数值、LeaseDD 旧版为文本。源 Excel 格式仍全部写“万”，而页面及保存原始响应部分为“亿”。候选代码只对此模块复用经货币资金、存货验证的原值后缀数值化；单测先失败再通过。德方纳米生产保存响应生成候选文件后，原站与 LeaseDD 的单元格值和类型差异均为 0；仍有 10 格格式差异，均是源 Excel 标“万”而原文为“亿”，不反向修改来源。四家公司保存批次只读候选导出均可打开，非空金额格均为数值：金银河 `9×15/74`、德方纳米 `11×13/73`、气派科技 `7×11/45`、昊志机电 `7×16/66`。后三家尚未逐格比对各自原站 Excel。

「非经常性损益」无需修：德方纳米原站与当前生产导出均为 `11×13`，全表单元格值、类型和非空格式差异均为 0。它原已走数值附注导出路径，不能把财务费用的问题扩展到该栏目。完整后端回归 364 通过/3 跳过（已有 AnyIO 弃用警告），前端 64 通过且构建成功；财务费用修正尚待镜像部署及生产烟测。六栏目全量验收继续进行。

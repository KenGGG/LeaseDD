# 开发目标与后续步骤

本轮仅推进 M0/M1。用户要求的本地 WebUI 已纳入首轮，原设计包中对应排除项被替代；原设计包保持不改。

| 阶段 | 能力 | 当前状态与下一步 |
|---|---|---|
| M0 | 环境、契约、采用边界、模板与公式冻结 | 已建立锁定环境、Schema、合成模板；真实上游 commit 未核实，默认不移植代码 |
| M1 | 多人 WebUI 完整合成链路 | 本轮实现；生产 Word 模板缺失，定稿禁用 |
| M2 | PDF/DOCX/XLSX 接入、多主体、期间单位、三表勾稽、冲突工作流 | 尚未实现；先扩展定位器与 Observation/FactSelection，按 F/E 验收矩阵推进。当前仅 UTF-8 文本事实验证 |
| M3 | 生产框架、完整问题证据包、全章编辑、真实 Agnes 验证 | API 适配已实现，真实端点未验证；需实际框架、模板及可用 Agnes 配置。扩展受控编辑和差异比较 |
| M4 | 风险问询、综合检查、独立审核和发布 | 尚未实现；冻结提交快照，增加退回、确认、过期审核及发布事务，不启用自审 |
| M5 | 依赖级增量、真实项目、故障／备份恢复全面验收 | 尚未完成；当前所有资料变化使项目结果失效，不宣称局部增量已实现。分别回归上市公告、非上市多账、联合承租／保证人 |

后续阶段开始前，补充生产框架和模板、目标 Word/WPS 软件环境、资料授权规则。租金模型需业务选择与公式确认，不以默认等额本息替代合同。

进一步的账号停用／重置密码、成员变更、授权撤销、完整审计检索、模板版本管理和资料删除需要在生产就绪前完成。实时共同编辑不列入首版。
